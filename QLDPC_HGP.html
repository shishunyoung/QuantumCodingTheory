QLDPC 的构造方法

在量子纠错中，拓扑码（Topological Code） 通常指的是一类基于流形（Manifold） 或复形（Cellulation of a Manifold） 的几何结构来定义的码。其特征是(1)几何局域性：稳定子生成元只作用于空间上相邻的量子比特。(2)拓扑保护：纠错能力来源于底层空间的拓扑性质（如亏格），而非复杂的代数构造。

Toric Code 环面码

环面码 toric code 属于 CSS 码，其定义需借助环面。
环面码参数为 [[2L2,2,L]][[2L^2,2,L]][[2L2,2,L]] ，LLL 是环面展开后的网格边长，L2L^2L2 为网格数，或者也可以写成 [[n,2,n/2]][[n,2,\sqrt{n/2}]][[n,2,n/2​]]。

上述三幅图展示了从环面出发，对环面网格化（cellulation），将网格平铺开变为平面周期网格的过程。

上图表示

  • 为网格中的每个edge分配一个qubit（上图黑点）
  • 为网格中的每个vertex分配一个X parity check（上图蓝色十字的中心点）
    • 该蓝十字覆盖了4个qubit，代表对应的X校验算符在这4个qubit上为 XXX，其余qubit上为 III
    • X parity check的PCM HXH_XHX​ 每行对应一个蓝色十字，每列对应一个物理比特。HXH_XHX​ 恰好是vertex与qubit的邻接矩阵
  • 为网格中的每个face分配一个Z parity check（上图红框内的方块）
    • 该方块的边框（红线）覆盖了4个qubit，代表对应的Z校验算符在这4个qubit上为 ZZZ，其余qubit上为 III
    • Z parity check的PCM HZH_ZHZ​ 每行对应一个红色方框，每列对应一个物理比特。HZH_ZHZ​ 恰好是face与qubit的邻接矩阵
  • 注意到每个X parity check和Z parity check要么有0个，要么有2个qubit重叠，是偶数，因此所有X/Z parity check算符都彼此对易。
    • 即 HXHZT=0H_X H_Z^T = 0HX​HZT​=0
  • 每个parity check只涉及 4 个qubit，每个qubit也只涉及 4 个parity check。因此它的校验矩阵 PCM 必定是稀疏的，HHH 每行每列只有4个非零元素。因此 toric code 属于 QLDPC 码。

以上图边长 L=3L=3L=3 的网格为例，他有 2L2=182L^2=182L2=18个物理比特，L2=9L^2=9L2=9 个Z parity check，L2=9L^2=9L2=9 个X parity check。不难发现，所有 L2L^2L2 个 Z parity check 算符相乘得到单位阵，因为每条边恰好出现2次，少了任何一个 Z parity check都无法得到单位阵，因此真正独立的 Z parity check 个数为 L2−1L^2-1L2−1。同理对 X parity check 也成立。所以逻辑比特数为物理比特减去独立的parity check个数，即可表示的逻辑比特数为 2，无论 LLL 是多少，Toric Code 都只能表示 2 个逻辑比特。

关于环面码的距离，有以下事实：

  • 距离定义为不可探测的、且non-trivial的泡利算符的最小权重。
  • 我们考虑只含有 ZZZ 的泡利算符，这些 ZZZ 出现在哪些qubit(边)上才会无法被X parity check探测？若该算符无法被一个蓝色十字探测，说明该蓝色十字的4条边必定有偶数个边被施加了 ZZZ，即只能是0,2,4条边。这表示所有被 ZZZ 作用的边必定形成一个无端点的封闭环路。
    • 任意1个或若干个face集合的边界正是这样的不可探测环路（上图左）。
    • 由于是周期网格，一条从上到下，或从左到右的线路也是无端点的封闭环路（上图中）。
  • 还要求 non-trivial，这就必须排除掉 face 集合的边界，因为这些边界对应几个Z parity check的乘积，对合法码字毫无作用。
    • 所以只能是利用网格周期性，从上到下、从左到右或兼具两个方向的封闭环路（上图右）。
    • 这种环路最短为 LLL。

因此符合要求的泡利算符的最小权重就是 LLL。

Topological Codes 拓扑码族与 Chain Complex 链复形

surface code 表面码，属于拓扑码族。

一个表面码的构建经理以下步骤：

  1. 对一个给定的表面进行网格化。
  2. 将qubit放置于网格的边上，一条边对应一个qubit。
  3. 每个节点 vertex 对应一个 X parity check。
  4. 每个网格面 face 对应一个 Z parity check。

物理比特的数量 = EEE
独立 X parity check 的数量 = V−1V-1V−1
独立 Z parity check 的数量 = F−1F-1F−1
逻辑比特数量 = E−(V−1)−(F−1)=2−(F−E+V)=2−χ=2gE - (V-1) - (F-1) = 2-(F-E+V) = 2-\chi = 2gE−(V−1)−(F−1)=2−(F−E+V)=2−χ=2g

ggg 为曲面的亏格。亏格：g=1−χ/2g=1-\chi/2g=1−χ/2，球面亏格为0，环面亏格为1，双环面亏格为2。
例如，根据欧拉多面体公式，凸多面体始终满足 F−E+V=χ=2F-E+V = \chi = 2F−E+V=χ=2，χ\chiχ 为 Euler Characteristic。

因此，环面拓扑码，即 toric code 环面码，亏格为1，有2个逻辑比特，这跟如何划分网格无关，只跟曲面的拓扑性质有关（即亏格）。

结论：对于一个亏格为 ggg 的曲面，基于该曲面的 surface code，可编码的逻辑比特数为 2g2g2g。
例如：无论网格如何划分，基于双环面的曲面码，一定只能表示4个逻辑qubit。

缺点：无论物理比特数 nnn 如何增加，逻辑比特数 kkk 固定不变，即随着 nnn 增加码率会趋于0。

chain complex 链复形

0-chain 是一个 v∈Z2Vv \in \mathbb{Z}_2^Vv∈Z2V​

  • Z2V\mathbb{Z}_2^VZ2V​ 是所有长度为 VVV 的 0/1 向量。VVV 为节点的数量。
  • 通俗的说 Z2V\mathbb{Z}_2^VZ2V​ 是节点集的所有子集组成的集合。
  • 任意1个 vvv 代表一个节点子集，被选中的节点赋予 1，没有选中的赋予 0。

1-chain 是一个 e∈Z2Ee \in \mathbb{Z}_2^Ee∈Z2E​

  • Z2E\mathbb{Z}_2^EZ2E​ 是所有长度为 EEE 的 0/1 向量。EEE 为边的数量。
  • 通俗的说 Z2E\mathbb{Z}_2^EZ2E​ 是边集的所有子集组成的集合。
  • 任意1个 eee 代表一个边子集，被选中的边赋予 1，没有选中的赋予 0。

2-chain 是一个 f∈Z2Ff \in \mathbb{Z}_2^Ff∈Z2F​

  • Z2F\mathbb{Z}_2^FZ2F​ 是所有长度为 FFF 的 0/1 向量。FFF 为面的数量。
  • 通俗的说 Z2F\mathbb{Z}_2^FZ2F​ 是面集的所有子集组成的集合。
  • 任意1个 fff 代表一个面子集，被选中的面赋予 1，没有选中的赋予 0。

所有 iii-chain 的集合记作 CiC_iCi​。

boundary map 边界映射
∂2\partial_2∂2​ 把 2-chain 映射为其边界 1-chain。
∂1\partial_1∂1​ 把 1-chain 映射为其边界 0-chain（所谓 1-chain 的边界是那些只连接了一条边的端点）。
每个边界映射对应一个校验矩阵(HX or HZH_X\text{ or }H_ZHX​ or HZ​)

  • 如果 1-chain 是一条闭合曲线，那么就不存在边界，其对应的 vvv 是一个全0向量。
  • 因为 2-chain 的边界必定是闭合曲线，所以有 ∂1∂2f=0\partial_1 \partial_2 f = 0∂1​∂2​f=0
  • 从下图可以看出，0/1/2-chain 不一定是连续的。

边界映射的数学形式为 ∂2(f)=e,∂1(e)=v\partial_2(f)=e, \partial_1(e)=v∂2​(f)=e,∂1​(e)=v，不难发现，它属于(模2加法的)线性映射：
∂2(f1)=e1,∂2(f2)=e2⟹∂2(f1+f2)=e1+e2\partial_2(f1)=e_1, \partial_2(f2)=e_2\Longrightarrow \partial_2(f1+f2)=e_1+e_2∂2​(f1)=e1​,∂2​(f2)=e2​⟹∂2​(f1+f2)=e1​+e2​

自然想到用矩阵来描述该映射，矩阵为 E×FE\times FE×F，每行/每列都是一个0/1向量，每一行代表一条边，每一列代表一个面。考察单独某一列，该面的边界对应的行设置为1，其余为0。
∂2=[cef]\partial_2 = \begin{bmatrix} & & &\\ & c_{ef}&&\\ & & & \end{bmatrix}∂2​=​​cef​​​​​

同理，对于 1-chain 到 0-chain 的边界映射，可以用一个 V×EV\times EV×E 的矩阵描述，每行/每列都是一个0/1向量，每一行代表一个节点，每一列代表一条边。考察单独某一列，该边的端点对应的行设置为1，其余为0。
∂1=[dve]\partial_1 = \begin{bmatrix} & & &\\ & d_{ve}&&\\ & & & \end{bmatrix}∂1​=​​dve​​​​​

  • 如果边 eee 正好是面 fff 的边界，则 cef=1c_{ef}=1cef​=1，否则为0。如果节点 vvv 正好是边 eee 的边界，则 dve=1d_{ve}=1dve​=1，否则为0。∂2,∂1\partial_2,\partial_1∂2​,∂1​ 矩阵的具体形式是跟网格化有关的。边界映射矩阵反映了点、边、面之间的邻接关系。
  • 注意到，将 ∂2\partial_2∂2​ 边界映射矩阵转置，就完全包含了 Z parity check 矩阵 HZH_ZHZ​（∂2\partial_2∂2​ 各列并不独立）。类似的, ∂1\partial_1∂1​ 边界映射矩阵（不用转置）包含了 X parity check 矩阵 HXH_XHX​（∂1\partial_1∂1​ 各行并不独立）。

1-cycles 满足 ∂1(e)=0\partial_1(e)=0∂1​(e)=0，即没有边界的 1-chain。
Z1={e:∂1(e)=0}Z_1 = \{e : \partial_1(e)=0\}Z1​={e:∂1​(e)=0}

阶段总结

从Toric Code到拓扑吗+链复形，我们是为了说明，“稳定子+校验矩阵”这套语言，可以用“链复形+边界映射”来代替。而接下来的内容将展示“链复形+边界映射+链复形张量积”能够构造更强大的超图乘积码 HGP Code。实际上 Toric Code 可看做是2个重复码做张量积得到的。

1-dimensional cell complexes 一维胞腔复形

1d胞腔复形(cell complex)由1d的边和0d的节点构成，并且存在 boundary map 边界映射将1d边的边界映射到某些0d节点。

1d胞腔复形的图形化表示如下，看着和 Tanner graph 很像。我们将展示，每个经典码都可以用1d chain complex来表示：

  • 所有1d边对应一种节点集合，总数记作 EAE_AEA​，其中的边记作 eAe_AeA​。
  • 所有0d点对应一种节点集合，总数记作 VAV_AVA​，其中的点记作 vAv_AvA​。
  • boundary map边界映射关系用 eAe_AeA​ 和 vAv_AvA​ 之间的连线描述。例如上图的 eAe_AeA​ 与3个 vAv_AvA​ 连接，就说明该边的边界是那三个节点。
  • 注意1d cell complex具备1d chain complex的代数结构：C1⟶∂1C0C_1 \overset{\partial_1}{\longrightarrow} C_0C1​⟶∂1​​C0​。注意链复形中边可对应任意数量的顶点。
  • 这个1d胞腔复形的图形表示和tanner graph一模一样，而tanner graph可以表示经典编码，因此可以用1d chain complex去描述一个经典码。
  • 别忘了tanner graph的校验节点和变量节点是彼此对称可互换的。因此在1d chain complex中，你可以把变量节点当做边 eAe_AeA​，校验节点当做顶点 vAv_AvA​，也可以反过来。

假设有一个经典码 CAC_ACA​，其tanner graph有 nAn_AnA​ 个变量节点和 lAl_AlA​ 个校验节点组成。若我们将变量节点对应1d链复形的边 eAe_AeA​，校验节点对应1d链复形的顶点 vAv_AvA​。则任意一个码字（无论是否合法）e∈Z2EAe \in \mathbb{Z}_2^{E_A}e∈Z2EA​​ 就对应一个1d-chain。

这里讨论的是经典码，链复形是1d的，1-boundaries B1={0}B_1=\{0\}B1​={0}，那为什么要定义它？后续为什么要依托他做商群？商群操作对经典码完全是trivial的。

其实这是为量子码的讨论做准备，在拓扑量子码中，我们将

  • 链复形的节点视作X校验节点(经典码的奇偶校验)
  • 面看作Z校验节点(经典码中无对应)
  • 边视作物理qubit(经典码的bit)

上述链复形/1-cycles/1-boundaries/同调群的语言，可以算出存在多少个彼此不等价的逻辑Z操作，从而确定他能表示多少个逻辑量子比特？

我们考虑 Z 误差算符，即只包含 I,ZI,ZI,Z 的算符。为了通过 X 校验，Z 算符作用的qubit必须首尾相接形成 1-cycles。这很好理解，X校验对应上述经典码的PCM HHH 矩阵，从而等价于边界映射矩阵 ∂A\partial_A∂A​，“通过X校验”就是 ∂A(e)=0\partial_A (e)=0∂A​(e)=0。这表示，所有无法探测的 Z 误差算符，必定属于 1-cycles。

我们能简单的把“无法探测的 Z 算符”当做 Z 逻辑比特操作吗？当然不可以，其中存在大量的冗余。例如考虑两个不可探测的 Z 算符e1,e2e_1,e_2e1​,e2​，假设存在一个 Z 校验稳定子 ZhjZ^{h_j}Zhj​(所有Z稳定子都属于1-boundaries)，使得 e1=Zhje2e_1 = Z^{h_j} e_2e1​=Zhj​e2​，由于 ZhjZ^{h_j}Zhj​ 不改变合法量子态，因此 e1,e2e_1,e_2e1​,e2​ 对合法量子态的作用效果完全相同，因此我们说 e1,e2e_1,e_2e1​,e2​ 是等价的，二者同属于一个等价类。所有同属于一个等价类的 Z 算符都对应同一种 Z 逻辑比特操作，我们得去除冗余。

不难发现，e1=Zhje2e_1=Z^{h_j}e_2e1​=Zhj​e2​ 表示1个 1-cycle 环路 e2e_2e2​ 可通过叠加上一个 1-boundaries 边界 ZhjZ^{h_j}Zhj​ 变化为另1个 1-cycle 环路 e1e_1e1​ ，这就是为什么要用 1-cycles 与 1-boundaries 做商群(quotient group)来寻找彼此不同的等价类。

H1=Z1/B1H_1=Z_1/B_1H1​=Z1​/B1​ 假设有4个等价类，说明存在4种彼此不等价的 Z 逻辑操作。表明该量子码可表示 log24=2\text{log}_{2}4=2log2​4=2 个逻辑比特。
